# funobotz

A modern web app built with TanStack Start, React, TypeScript, and Tailwind CSS.

## Overview

funobotz is a starter project for building fast, scalable, and modern web experiences with a powerful developer workflow. It uses the TanStack ecosystem and a Vite-based setup to provide excellent DX, strong typing, and a clean component architecture.

## Features

- React 19 + TypeScript
- TanStack Start integration
- Tailwind CSS styling
- shadcn/ui-compatible component structure
- Vite-based development workflow
- Vitest for testing
- Linting and formatting support

## Tech Stack

- React
- TypeScript
- TanStack Start
- TanStack Router
- Tailwind CSS
- shadcn/ui
- Vitest
- ESLint + Prettier

## Prerequisites

Before you begin, make sure you have the following installed:

- Node.js 18 or newer
- npm or bun

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/KarthikManivannan1710/funobotz.git
cd funobotz
```

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```

The app will be available in your browser at the local Vite/TanStack dev server URL.

## Available Scripts
